# TS-Blog

Demo editorial blog site: **Some Convictions Apply**

Tagline: *Leave your bias at the door. We have our own.*

## Run locally

Use any static server from the repository root. For example:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173` in your browser.

## Notes

- The hero image is loaded from Unsplash (`images.unsplash.com`) to avoid committing binary assets in this demo repository.
